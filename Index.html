🔥 Configuração do Banco de Dados (Firebase — Gratuito)

Para ativar o banco de dados online e o robô de disparo automático, siga 3 passos:

1. Acesse console.firebase.google.com → Crie um projeto gratuito (plano Spark)

2. Vá em Firestore Database → Criar banco de dados (modo teste, 30 dias gratuitos)

3. Em Configurações do Projeto → Seus apps → Web, copie o firebaseConfig e cole no início deste arquivo HTML

🤖 Robô de disparo: após configurar o Firebase, utilize o Google Apps Script (gratuito) com um gatilho por tempo (a cada 1h) para checar o Firestore e enviar via API do WhatsApp Business ou CallMeBot.
